Privacy Policy — Newbie Investing Uploader

Last updated: 2026-10-11

Newbie Investing Uploader is a private tool that uploads videos to the Newbie Investing YouTube channel on behalf of the channel's owner. It is used only by that owner.

YouTube API Services

This tool uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data the tool accesses and stores

  • With the account owner's permission, the tool uploads videos, thumbnails and captions to the owner's own YouTube channel and reads that channel's name to confirm it is the right one.
  • It stores one sign-in token, only on the owner's own computer, so it can upload without signing in each time.
  • It does not collect, store or share any information about viewers or any other person.
  • It shares no data with third parties and uses no cookies or analytics.

Revoking access

Access can be revoked at any time on the Google security settings page. Deleting the token file on the computer removes the stored sign-in.

Data retention and deletion

The tool keeps no copy of any YouTube data. The only thing it stores is the sign-in token described above, which is deleted when access is revoked or the file is removed. Videos uploaded to the channel can be deleted at any time in YouTube Studio.

Contact

Questions about this policy can be sent through the Newbie Investing YouTube channel.
